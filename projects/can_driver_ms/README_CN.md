# LK 双轴云台控制器

面向实际工程的双轴云台控制程序，硬件为 XIAO STM32C5、MS3506V3 Yaw、
MS3008V3 Pitch 以及 Seeed Studio 圆形显示触摸屏。

English documentation: [README.md](README.md)

## 固定配置

| 轴 | 电机 | CAN ID | 机械硬范围 | UI 工作范围 | 固定中心 |
| --- | --- | ---: | ---: | ---: | ---: |
| Yaw | MS3506V3 | `0x141` | `0..345°` | `1..344°` | `172.5°` |
| Pitch | MS3008V3 | `0x142` | `0..180°` | `1..175°` | `90°` |

总线固定使用经典 CAN 2.0、1 Mbit/s、11-bit ID 和 8 字节报文，不扫描波特率
或节点 ID。

## 运行架构

程序分成两个执行上下文：

1. **电机线程**：高优先级、10 ms 普通轮询。负责处理 CAN RX 队列、推进云台
   状态机、发送读取/使能/停止/位置命令、检查限位并报告通信故障。
2. **UI 线程**：读取 CHSC6X 触摸并刷新 GC9A01。它只提交启动、重新回中和
   滑条目标。显示使用加锁快照，因此耗时的屏幕传输不会阻塞电机控制。

应用层不使用中断函数控制电机。Zephyr CAN 驱动底层可以使用硬件中断，但业务
逻辑是普通的非阻塞线程和状态机。

## 状态机

| 状态 | 行为 |
| --- | --- |
| `DISARM` | 电机停止，低频 `0x90` 读取用于确认节点在线。 |
| `CHECK` | 丢弃缓存角度，只接受操作请求之后的新反馈。 |
| `CENTER` | 使能两轴，各发送一次低速 `0xA8` 相对位置命令。 |
| `READY` | 解锁滑条；仅在目标变化时发送运动命令。 |
| `FAULT` | 发送停止命令并锁定故障状态。 |

每次 START 或 CALIBRATE 都恢复固定中心 `172.5°/90°`；滑条目标不会成为新的
机械中心。

## 角度换算和抖动处理

实测 V3 电机在 `0x90 DATA[4:5]` 返回 15-bit 单圈 raw 值。当前标定参数为：

- Yaw：中心 raw `12178`，方向 `+1`，`91.8087 counts/°`。
- Pitch：中心 raw `8445`，方向 `+1`，`93.4083 counts/°`。

`0xA8` 发送“目标机械角度－当前机械角度”的有符号增量。它不是绝对位置命令，
因此程序不会在反馈未更新时重复叠加同一增量。

MS3506 Yaw 在约 `172°` 附近持续位置保持时存在明显高频 PID hunting。Yaw
进入目标容差后发送 `0x81 STOP`；下一次移动 Yaw 滑条时先发送 `0x88`，等待
异步发送完成，再发送一次新的 `0xA8`。MS3008 Pitch 到位后继续闭环保持，用于
承托垂直负载。

## 安全保护

- 两轴均取得新鲜 `0x90` 反馈且角度位于硬限位内，才允许运动。
- 启动反馈必须小于 1 秒。
- 运行反馈看门狗、CAN TX 错误日志和分轴 RX 计数。
- 回中误差比起点增大超过 3°时立即停止两轴。
- 回中超时保护；端点采样和编码器量化保留 1°反馈容差。
- 每台电机最多一个异步待发送帧，避免 TX FIFO 堆积。
- UI 工作范围与机械硬限位保留安全余量。

## 界面

- 两个滑条同时显示目标角度和实测角度。
- 操作按钮提交首次回中或重新回中请求。
- 故障文字显示为红色，按钮按下时立即变色。
- 主色：`#8FC31F`、`#004966`。
- 背光 PWM：80%。

## 编译

在仓库根目录执行：

```powershell
pio run -d projects/can_driver_ms -e seeed-xiao-stm32c5
```

输出：`.pio/build/seeed-xiao-stm32c5/firmware.uf2`。

## 关键文件

- `include/app_config.h`：ID、限位、标定映射、速度和时序。
- `src/lkm_motor.c`：经典 CAN 传输与 V3 反馈换算。
- `src/gimbal.c`：电机状态机、安全策略和目标生命周期。
- `src/main.c`：线程隔离、CAN 初始化和 UI 快照。
- `src/round_ui.c`：显示绘制和 UI 事件。
- `src/touch.c`：CHSC6X 轮询。

协议资料：[LK Motor CAN 协议 V2.3](../../docs/LK-Motor-CAN-Protocol-V2.3.pdf)。
